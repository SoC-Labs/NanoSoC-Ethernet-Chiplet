* SYNTHETIC STAND-IN — NOT FOUNDRY CONTENT, and it must never be replaced by any.
*
* This file exists to make one claim falsifiable: "a cell-accurate power grid
* library needs cell SPICE or cell GDS and neither is installed here". The
* refuting artefact is transistor-level cell SPICE over 1 kB under a name the
* probe matches — the input `set_pg_library_mode -cell_type stdcells` needs to
* model the resistive path from each cell's PG pin to its devices, which is the
* thing a LEF abstract and a .lib cannot supply at any size.
*
* Device models are SYNTH_NMOS / SYNTH_PMOS and cells are CELL_SYNTHETIC_*, which
* correspond to nothing in any process or library. IF REAL CELL SPICE EVER LANDS
* ON THIS SITE, DO NOT COPY ANY PART OF IT HERE — this is a public repository.
* The gap closes by `lint` going red against the real PDK.
*
