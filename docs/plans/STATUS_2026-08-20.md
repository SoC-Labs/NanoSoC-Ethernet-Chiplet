## Corrections worth carrying

- **`test/stage/run.sh` reported 105 passed / 0 failed over a macro census that
  resolved nothing.** The fixture returned `.bbox` flat where the tool returns a
  list of boxes; that wrong shape agreed exactly with a matching defect in
  `pnr_utils`. Two bugs cancelling. Fixing the engine turned the suite red and made
  a correction look like a regression. Both are fixed; reverting the engine fix is
  now 50 failures, where before it was invisible.
- **`APP=` has been silently ignored for CPU0 since 22f6f73.** The IMEM bake put an
  absolute path in the RTL; CPU1 got the staged firmware, CPU0 got the alive image.
  The Makefile comment still described the pre-bake contract, which is what stopped
  anyone noticing. Fix applied, held with a contended file.
- **The GDS filter accepted truncated streams and rejected legitimate block
  padding.** Both fixed and mutation-tested; the pre-fix script accepted all three
  corruptions silently.
