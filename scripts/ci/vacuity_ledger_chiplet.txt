# THE CHIPLET HALF OF THE VACUOUS-GATE LEDGER.
#
# ASIC/asic-toolkit/ci/check-vacuous-gates.sh censuses `flow tech ci mk scripts
# test` UNDER THE TOOLKIT. Its corpus has therefore never contained one line of
# this chiplet: not ASIC/genus-innovus/scripts (the place-and-route stage
# scripts), not scripts/ci (every signoff gate in this repository), not
# ASIC/sta, not verif/lint. 205 files scanned, and the design's own gates were
# all outside them.
#
# scripts/ci/vacuity_scan.sh points it here as well -- 348 files, +143 -- and
# the first run found 14 undeclared instances in this chiplet that the scanner
# had been unable to see since the day it was written. They are triaged below.
# The toolkit tree is read-only from this repository (see the user-level rule on
# shared IP and vendor collateral, and ASIC/asic-toolkit's own contract), so this
# file is merged with the toolkit's ledger at scan time rather than edited into
# it. ONE entry below is a TOOLKIT finding, marked as such: it belongs upstream
# and is triaged here only because that is the file this repository can write.
#
# `real` DOES NOT MEAN WAIVED. A real entry is printed as a WARN every run with
# its owner, and stays until somebody fixes it or argues it down to by-design.
# Seven of the fifteen below are real, and four of those seven are in
# scripts/ci -- gates this harness owns.
#
# ALL FIFTEEN WERE READ, not pattern-matched. Each note answers the question the
# rule cannot: does the stage still ASSERT the thing it claims to measure when
# the shape fires?
